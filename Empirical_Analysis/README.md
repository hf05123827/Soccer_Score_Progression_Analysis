# Empirical Analysis

## 1. 目的
　*Dixon&Robinson* (1998)モデルは、0-0、1-0のようなスコア状況ごとに得点のハザードを変化させている。
このような分類の他にハザードに影響する特徴を抽出するために、得点間の待ち時間を経験的に分析する。

　待ち時間に影響を与えうる要因を、ロジカルツリーによって次の3つに分類し、それぞれ分析する。

- **実力差**（Skill_Gap）
- **試合状況**（Match_Status）
- **時間帯**（Time_Zone）

## 2. 分析方法（共通）
　StatsBomb Open Data の全リーグ・全シーズンの `*_goals_and_red_cards.csv` を用いる。

　各チームについて「**次に自チームが得点するまでの待ち時間**」を、打ち切りを考慮した生存時間分析
（Kaplan-Meier曲線・ログランク検定）で分析する。

　試合をキックオフ・各得点・試合終了で区間に区切り、得点が入るたびに home・away 双方の観測を終了して、
その時点から新しい観測を始める。1つの区間からは home・away の2件の観測ができ、各観測は次のいずれかで終わる。

| 観測の終わり方 | 内容 | 図中の色 |
|---|---|---|
| イベント | そのチーム自身が次に得点した | － |
| 打ち切り（相手の得点） | そのチームより先に相手チームが得点した | 赤 |
| 打ち切り（試合終了） | その状態のまま試合終了を迎えた | 青 |

　無得点で終わった試合も、home・away とも「0-0・試合終了による打ち切り」の観測として含める。
各フォルダの `figures/` に図を保存している。

## 3. 各分析

### Skill_Gap（実力差）
　両チームの実力差の区分ごとに、次の得点までの待ち時間を比較する。実力差は試合中は一定。

| ファイル | 内容 |
|---|---|
| `survival_final_point_gap.ipynb` | シーズン終了時点の勝ち点差（`final_points` の差）を7分位で区分する |
| `survival_provisional_point_gap.ipynb` | 試合開始時点の暫定勝ち点から求めた1試合あたり勝ち点（PPG）の差を6分位で区分し、シーズン進捗率（8区分）ごとに比較する |

　シーズン終了時点の勝ち点は試合前には分からない情報なので、`survival_provisional_point_gap.ipynb` では
試合開始時点で分かる暫定勝ち点を使っている。

### Match_Status（試合状況）
　その時点のスコアや、直前にどちらが得点したかによって、次の得点までの待ち時間を比較する。
スコアは各チームから見た「自チームの得点 - 相手の得点」で表す。

| ファイル | 内容 |
|---|---|
| `survival_score_difference.ipynb` | スコアで9区分（0-0、1-0、0-1、1-1、2-2以上の同点、高スコアの1点差リード・ビハインド、2点以上のリード・ビハインド） |
| `survival_recent_score.ipynb` | 「リード／同点／ビハインド」×「直前の得点が自チームか相手か」の7区分（0-0を含む） |
| `survival_score_progression_patterns.ipynb` | 同じスコア（1-1、2-1、1-2、2-2）に、自チームの得点で到達したか相手の得点で到達したかの2区分を比較 |

　`survival_recent_score.ipynb` の7区分は、`Models/recent_scorer_model.ipynb`（直近得点者モデル）の区分のもとになっている。

### Time_Zone（時間帯）
　得点が試合のどの時間帯に起こりやすいかを見る。

| ファイル | 内容 |
|---|---|
| `scoring_time.ipynb` | 得点時刻の分布を、1分刻み・5分刻みのヒストグラムとカーネル密度推定で描く。正規化した試合時間（`dr_time`、0〜1）でも描く |
